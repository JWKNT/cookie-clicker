Cookie Monster+ patcher

Autoplay mod

This tool installs Cookie Monster+ as a local mod beside Cookie Monster. Cookie Monster+ plays by the rules in the guide. It clicks, buys, manages every minigame and ascends at the optimal time. Each system has a switch in the settings. Version 2.053.13 publishes a readable build and the full source.

  1. Subscribe to Cookie Monster in the Steam Workshop. Start Cookie Clicker once.
  2. Download the patcher and extract the archive.
  3. Double-click Install Cookie Monster Plus.command on macOS or the .bat file on Windows. On Linux, run python3 install_cookie_monster_plus.py.
  4. Restart Cookie Clicker. The autoplay settings are in Options, under Cookie Monster.

Verification and removal

The patcher downloads the current build and checks every file against its published SHA-256 digest. It does not change your save. Python 3.9 or newer is necessary.

If the patcher does not find the game, drag the Cookie Clicker folder into its window. If macOS blocks the file, Control-click it and select Open.

Run the patcher with --verify to check an installation, or with --uninstall to remove Cookie Monster+. An earlier copy moves to mods/.cookie-monster-plus-backups. The Workshop copy of Cookie Monster stays unchanged. If both mods are on, only Cookie Monster+ runs.

Browser version

In the browser version of the game, open the developer console and enter this line:

Game.LoadMod('https://jehlp.net/cookie-clicker/mod/main.js')

The mod does not stay installed after you reload the page.

Build from source

The folder source/cookie-monster-plus contains the full source. Node.js 22 or newer is necessary.

Run npm ci, npm test and npm run build:mod in that folder. The build writes mod/main.js, which is identical to the published file.

Before installing

Keep a copy of your save before you install any mod. Turn off other autoplay mods, because two mods that buy and click at the same time interfere.
