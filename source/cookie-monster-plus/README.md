# Cookie Monster+

Cookie Monster+ is Cookie Monster with mathematically optimal autoplay for *Cookie Clicker*. The guide at
<https://jehlp.net/cookie-clicker/> explains the rules that it plays by, and the paper at
<https://jehlp.net/cookie-clicker/paper.pdf> proves them.

This folder is a fork of [Cookie Monster](https://github.com/CookieMonsterTeam/CookieMonster) by the
Cookie Monster Team. See [`../README.md`](../README.md) for the build and release steps, and
[`LICENSE.md`](LICENSE.md) for the license.

- `npm ci` installs the dependencies.
- `npm test` runs the unit tests.
- `npm run build:mod` writes the readable build to `../../mod/main.js`.
